# Fictional Student Dataset

A fictional dataset of 50 students generated using Python for my Assignment.

## Fields
- **Student_ID** – Unique identifier (e.g., STU1001)
- **Department** – Academic department
- **Level** – Academic level (100, 200, 300, 400)
- **Attendance_Percentage** – Class attendance (%)
- **Average_Exam_Score** – Average exam score (%)

## Files
- `student_dataset.py` – Python script that generates the dataset
- `students.csv` – The generated dataset

## How to Run
Run the following command in your terminal:
```bash
python student_dataset.py
